# Zippy Central Cafe & Bar — client demo

A proposed website for Zippy Central Cafe & Bar in Rotorua, using the client-supplied official logo and a complementary green, orange and charcoal palette.

## Demo features

- Responsive café homepage, menu highlights, directions and contact links.
- Proposed direct ordering: sample menu, basket, quantity changes, pickup/delivery selection and order review.
- Explicit demo notices: no orders are submitted, no payments are processed and no personal details are collected.
- Illustrative prices and delivery arrangements subject to client approval.

## Preview locally

From this directory, run `python3 -m http.server 4173`, then open http://localhost:4173.

This is a static HTML/CSS/JavaScript site. No installation or build step is required. GitHub Pages can serve the root of the `main` branch.

## Assets and approval

The official logo was supplied by the client. Existing café photos and research sources are documented in `credits.html`. Photo rights are retained by their respective owners; no open-source license is granted for those assets. Public launch requires business approval and confirmation of photography permissions, current menu details, opening hours, and ordering operations.
